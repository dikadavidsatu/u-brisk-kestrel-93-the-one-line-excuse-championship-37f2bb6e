An entry for make.fun's "The One-Line Excuse Championship". The program prints exactly one line — a single excuse for being late, built from three beats (apology, confession, legal consequence): the snooze button was hit so often that the alarm clock filed a restraining order, and the narrator is now legally required to wake up 500 feet away from it. Before printing, the program validates the line against the championship gate (one line, within the character budget, no stray whitespace) and exits non-zero without printing if the line ever failed. The output is fully deterministic: no clock, no randomness, no input.

## Run it

```sh
node main.ts
```
